# Heart Disease Classification with MLP and 1D-CNN

Лабораторная работа №2 по классификации табличных данных на основе нейросетевых моделей.

Проект посвящён классификации пациентов по наличию сердечного заболевания на основе набора признаков Heart Disease UCI. В работе выполняется полный цикл анализа данных: загрузка датасета, разведочный анализ, очистка, создание новых признаков, отбор существенных признаков, кодирование категориальных переменных, стандартизация, обучение нейросетевых моделей и сравнение качества до и после подбора гиперпараметров.

## Рекомендуемое название репозитория

```text
heart-disease-classification-mlp-cnn
```

## Основной файл проекта

```text
ЛР2_ИАДНОММО.ipynb
```

## Описание задачи

Необходимо решить задачу бинарной классификации: определить наличие или отсутствие сердечного заболевания у пациента по медицинским признакам.

Целевая переменная:

```text
target
```

Значения целевой переменной:

```text
0 — отсутствие заболевания
1 — наличие заболевания
```

## Используемый датасет

В ноутбуке используется файл:

```text
V3_classification_lr3.csv
```

Датасет содержит 1025 записей и 14 признаков, включая целевую переменную `target`.

Признаки датасета:

- `age` — возраст пациента;
- `sex` — пол;
- `cp` — тип боли в груди;
- `trestbps` — артериальное давление в покое;
- `chol` — уровень холестерина;
- `fbs` — уровень глюкозы натощак;
- `restecg` — результат ЭКГ в покое;
- `thalach` — максимальная частота сердечных сокращений;
- `exang` — стенокардия при физической нагрузке;
- `oldpeak` — депрессия сегмента ST;
- `slope` — наклон сегмента ST;
- `ca` — количество окрашенных сосудов;
- `thal` — показатель талассемии;
- `target` — наличие или отсутствие сердечного заболевания.

## Цель работы

Цель проекта — построить и сравнить нейросетевые модели для классификации табличных медицинских данных.

В рамках работы выполнены следующие задачи:

- загрузка и первичный анализ данных;
- проверка пропусков и дубликатов;
- одномерная и многомерная визуализация признаков;
- очистка данных от выбросов;
- удаление дубликатов;
- анализ корреляций между признаками;
- создание новых признаков;
- отбор существенных признаков;
- кодирование категориальных признаков;
- стандартизация данных;
- формирование четырёх вариантов датасета;
- разделение данных на train, validation и test;
- обучение MLP и 1D-CNN;
- сравнение качества моделей;
- выбор лучшей модели;
- подбор гиперпараметров с помощью Grid Search;
- сравнение модели до и после Grid Search.

### 2. Загрузка данных

После загрузки выполняется первичный анализ с помощью:

- проверки дубликатов.

На этом этапе установлено, что исходный датасет содержит 1025 записей и 14 признаков.

### 3. Разведочный анализ данных

В ходе разведочного анализа изучаются распределения числовых и категориальных признаков.

Для числовых признаков рассматриваются:

- `age`;
- `trestbps`;
- `chol`;
- `thalach`;
- `oldpeak`.

Для категориальных и дискретных признаков анализируются:

- `sex`;
- `cp`;
- `fbs`;
- `restecg`;
- `exang`;
- `slope`;
- `ca`;
- `thal`;
- `target`.

Визуализация помогает оценить распределения, выявить возможные выбросы и понять структуру медицинских признаков.

### 4. Очистка данных

Очистка выполняется в два этапа:

1. Удаление выбросов методом IQR для признаков:

 - `trestbps`.

2. Удаление дубликатов.

После удаления выбросов размер датасета уменьшился с 1025 до 965 записей.

После удаления дубликатов осталось 284 уникальные записи.

Баланс классов после очистки:

```text

```

Это показывает, что данные имеют небольшой дисбаланс, но он не является критическим.

### 5. Корреляционный анализ

В работе строится корреляционная матрица и анализируется связь признаков с целевой переменной.

Наиболее заметные связи с `target`:

- `thalach`: 0.426;
- `cp`: 0.419;
- `slope`: 0.328;
- `oldpeak`: -0.433;
- `exang`: -0.428;
- `ca`: -0.394;
- `thal`: -0.346;
- `sex`: -0.321.

Между признаками не выявлено сильной мультиколлинеарности: нет пар признаков с корреляцией выше 0.7.

### 6. Создание новых признаков

В ноутбуке создаются дополнительные признаки:

```text
chol_per_age
thalach_age_product
high_trestbps
oldpeak_group
cp_exang_interaction
```

Назначение новых признаков:

- `chol_per_age` — отношение холестерина к возрасту;
- `thalach_age_product` — произведение максимальной ЧСС и возраста;
- `high_trestbps` — бинарный индикатор повышенного давления в покое;
- `oldpeak_group` — группа по значению депрессии ST;
- `cp_exang_interaction` — взаимодействие типа боли в груди и стенокардии при нагрузке.

Новые признаки используются для проверки того, помогают ли физиологические взаимодействия улучшить классификацию.

### 8. Кодирование категориальных признаков

В построенном наборе данных кодируются признаки:

- `cp_exang_interaction`;
- `oldpeak_group`.

```text

```

После кодирования размер построенного набора изменился:


Исходный набор не требует кодирования, так как в нём отсутствуют текстовые категориальные признаки.

### 9. Стандартизация

Для стандартизации используется `StandardScaler`.

Стандартизация применяется к двум наборам:

- исходный закодированный набор;
- построенный закодированный набор.

В результате формируются четыре варианта данных:

1. исходный закодированный;
2. преобразованный исходный стандартизированный;
3. построенный закодированный;
4. преобразованный построенный стандартизированный.

Стандартизация особенно важна для нейросетевых моделей, так как признаки имеют разные масштабы.

### 10. Разделение данных

Каждый из четырёх наборов данных делится на три части:

### 11. Обучение моделей

В работе сравниваются две нейросетевые архитектуры:

- MLP — полносвязная нейронная сеть;
- 1D-CNN — одномерная сверточная нейронная сеть.

MLP используется как базовая модель для табличных данных.

1D-CNN добавляется по условию варианта и проверяется как альтернативная архитектура.

### 12. Метрики качества

Для оценки моделей используются:

- `accuracy`;
- `balanced_accuracy`;
- `f1_macro`;
- `f1_class0`;
- `f1_class1`;
- `AUC`.

Основной метрикой для сравнения выступает `f1_macro`, так как она учитывает качество классификации по обоим классам.

## Основные выводы

В ходе лабораторной работы были получены следующие выводы:

- стандартизация существенно улучшила качество нейросетевых моделей;
- MLP оказалась лучшей архитектурой для данной табличной задачи;
- 1D-CNN не дала преимущества, так как данные не имеют временной или пространственной структуры;
- удаление дубликатов сильно уменьшило размер данных, но сделало набор более корректным;
- построенные признаки оказались полезными для анализа, но лучший результат был получен на стандартизированном исходном наборе;
- SMOTE и `class_weight` не дали значимого улучшения на малом построенном наборе;
- Grid Search подтвердил устойчивость MLP и немного улучшил качество вероятностных предсказаний;
- итоговая модель достигла `F1_macro = 0.9805` на тестовой выборке.
